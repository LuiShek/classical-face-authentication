# Changelog

All notable changes to this project are documented here.

## 1.0.0 - 2026-11-14

### Added

- Interactive face registration and named-profile Login
- LBPH authentication with deterministic ORL and LFW evaluation
- Three-frame median pooling
- Active randomized head-turn liveness
- Encrypted background cohort and conservative per-user calibration
- Windows DPAPI protection for biometric models and crops
- Persistent exponential login lockout
- Reversible legacy biometric migration
- Classical baselines, confidence intervals, DET curves, and reports
